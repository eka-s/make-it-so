# デスクトップアプリを使う

デスクトップアプリは、艦を専用のウィンドウで開きます。艦の画面はポートでは配信しないので、ブラウザから届くものはありません。（クルーが呼ぶ掲示板の MCP は、今までどおり `127.0.0.1` で待ち受けます。ポートは起動のたびに OS が選び、全セッションに渡す秘密の値が要ります。）

## 開いたときの動き

- **艦がちょうど1隻:** すぐに開きます。
- **艦が複数、または0隻:** 一覧が出ます。艦を選ぶと、その艦が専用のウィンドウ（Dock のアイコンも別）で開き、一覧は閉じます。一覧の**設定**ボタンで、艦を作る設定画面を開けます。
- **艦がすでに開いている:** 同じ艦をもう一度開くと、2つ目は起動せず、そのウィンドウが前に出ます。
- **艦のウィンドウを閉じると、その艦は止まります。** クルーのセッションも一緒に終わります。
- **設定:** 一覧から、または艦のウィンドウのメニュー項目（macOS は `⌘,`）から開きます。設定の「艦」タブには、起動と停止の代わりに**艦を開く**ボタンがあります。開いている艦の削除は、拒否されます。

ファイルは今までどおり `~/.make-it-so` にあります。デスクトップアプリとブラウザ版は、同じ艦を読みます。**1つの艦は、どちらか一方でしか開けません**。片方で動いている艦を、もう片方で起動すると、メッセージを出して断ります（先に、ウィンドウを閉じるか、ブラウザ版を止めてください）。

## ソースから動かす

```
npm run build
npm run start:electron                 # 上のとおり（艦、一覧、設定のどれか）
npm run start:electron -- --ship alpha # 艦を1隻
npm run start:electron -- --settings   # 設定
```

## アプリを作る

```
npm run pack   # release/mac-arm64/Make-It-So.app（インストーラーにはしない）
npm run dist   # release/Make-It-So-<バージョン>-arm64.dmg
```

アプリには**署名がない**ので、ダウンロードしたファイルから開くと、macOS が警告することがあります。署名と公証には Developer ID の証明書が要りますが、ここでは用意していません。これまでに、ビルドして動かしたのは、macOS（Apple シリコン）だけです。

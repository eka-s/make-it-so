# 権限モードを変える

クルーが、ツールの実行前に艦長へ確認を求める範囲を変えます。

## 値

| 値（claude） | 意味 |
|---|---|
| `default` | 確認が必要な操作を、毎回確認する |
| `acceptEdits` | ファイルの編集は確認しない |
| `plan` | 計画だけを立て、実行しない |
| `auto` | 自動で判断する。**指定しないときの既定**（`touch` のような、状態を変えるコマンドも、承認なしで通る） |
| `bypassPermissions` | すべて、確認しない |

kiro は、権限モードを受け付けません（警告を出して、既定のまま動きます）。選べない値のとき（**綴りの間違いを含む**）も、警告を出して既定のまま動きます。**警告は、サーバーのログ（`logs/` と、起動したターミナル）にだけ出ます。画面には出ません。** claude の既定は `auto`（確認なしで通す）なので、確認を求めたいクルーは、起動のあと、ログに警告がないことを確かめてください。

## 手順

1. 設定ファイルに `permission_mode` を書きます。
   - メンバーの既定: `~/.make-it-so/roster.yml` の `crew.<メンバー>.permission_mode`
   - 艦での上書き: `ship.yml` の `crew.<役職>.permission_mode`（こちらが優先）
2. 反映します。**セッションの作成時に適用する**ため、動いているセッションには効きません。サーバーを再起動するか、クルーの人事記録からセッションを再起動します。

## 注意

- `bypassPermissions` は、クルーが、確認なしに、そのクルーの権限でファイルやコマンドを実行します。**認証のないサーバーで、周囲に影響する操作を許すことになります。** 範囲を理解した上で使ってください（[セキュリティ](../security.ja.md)）。
- 承認を求められたときの操作は、画面の入力欄の上のトレイで行います（[画面の挙動](../reference/behavior.ja.md#承認待ち)）。

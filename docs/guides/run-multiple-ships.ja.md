# 複数の艦を動かす

1 つの艦が 1 つのプロセスです。艦ごとに、専用のポート、専用の DB、専用のブラウザのタブを使います。

## 手順

1. `~/.make-it-so/ships/` の下に、艦のディレクトリを作り、`ship.yml` を置きます。**`port` は艦ごとに違う値**にします（重複は起動時のエラーです）。

   ```
   ~/.make-it-so/ships/
     alpha/ship.yml    # port: 3939
     beta/ship.yml     # port: 3940
   ```

2. ビルドは、一度だけです。

   ```
   npm run build
   ```

3. 艦ごとに、ターミナルを分けて、`--ship` を付けて起動します。

   ```
   npm start -- --ship alpha
   npm start -- --ship beta
   ```

4. それぞれのポートのページを、別のタブで開きます。

## 注意

- 艦が複数あって `--ship` を付けないと、候補を示してエラーになります。
- 艦同士で、DB・会話・ミッションは共有されません。
- 1 つの画面で、複数の艦をまとめて見ることはできません。
- 同じ名簿のメンバーを、複数の艦に配属できます。

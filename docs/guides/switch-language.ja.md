# 言語を切り替える

言語の設定は 2 つあります。

| 設定 | 対象 | 切り替え |
|---|---|---|
| UI の言語 | 画面の文言 | ヘッダーの言語の表示（クリックする） |
| クルーの言語 | クルーが話す言語 | 同じポップアップの、2つ目のスイッチ |

対応する値は `en` と `ja` です。

## 画面から切り替える

ヘッダーに、`EN / 日本語` のような小さな表示が出ます。左がUIの言語、右がクルーの言語です。ホバーすると意味が出て、クリックすると、「UI」と「クルー」の2つのスイッチのポップアップが開きます。

- 切り替えると、艦の DB に保存されます。以降は、その値が `config.yml` の既定より優先されます。
- UI の言語は、すぐ反映されます。
- クルーの言語は、**新しく作られるセッションから**反映されます。動いているセッションには効かないため、すぐ反映したいときは、クルーの人事記録からセッションを再起動します。

## 既定を変える

画面から一度も切り替えていない艦の既定は、`config.yml` に書きます。

```yaml
language: ja          # UI の言語（既定: en）
crew_language: ja     # クルーの言語（既定: language と同じ）
```

未対応の値は、起動時のエラーになります。

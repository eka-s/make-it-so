# 言語を切り替える

言語の設定は 2 つあります。

| 設定 | 対象 | 切り替え |
|---|---|---|
| UI の言語 | 画面の文言 | 左ペインの下の「設定」セクション。デスクトップアプリでは、表示メニュー |
| クルーの言語 | クルーが話す言語 | 同じセクション、または同じメニュー |

対応する値は `en` と `ja` です。

## 画面から切り替える

左ペインの下の「設定」セクションに、テーマ、UI の言語、クルーの言語を選ぶラジオボタンがあります。デスクトップアプリでは、表示メニューにも、同じ選択肢があります（メニューの言葉は、UI の言語に合わせて変わります）。左ペインは、ヘッダーの左のボタンで隠せます。選択肢を使うときは、もう一度出してください（狭いウィンドウでは、会話の上に開きます）。

- 切り替えると、艦の DB に保存されます。以降は、その値が `config.yml` の既定より優先されます。
- UI の言語は、すぐ反映されます。
- クルーの言語は、**新しく作られるセッションから**反映されます。動いているセッションには効かないため、すぐ反映したいときは、クルーの人事記録からセッションを再起動します。

## 既定を変える

画面から一度も切り替えていない艦の既定は、`config.yml` に書きます。

```yaml
language: ja          # UI の言語（既定: en）
crew_language: ja     # クルーの言語（既定: language と同じ）
```

未対応の値は、起動時のエラーになります。
